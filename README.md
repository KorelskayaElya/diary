# Проект собственный дневник для конспектов

В проекте есть возможность регистрировать пользователя. 
Пользователь может создавать карточки. 
Для пользователя и карточек реализована база даных.

## Библиотеки

Проект использует две библиотеки flask и flask-sqlalchemy

## Как загрузить проект

```
py -m venv venv
```


```
pip install flask
```

```
pip install flask-sqlalchemy
```
